# 🚀 Featured Projects

## 🎓 Admission Referral Management System

A full-stack web platform designed to **digitize and centralize student admission referrals** and provide a structured referral management workflow.

### ✨ Key Features

- 🔐 Role-based authentication
- 👥 Student, Faculty, Alumni, Consultant & Admin roles
- 🆔 Unique candidate identification
- 🚫 Duplicate referral prevention
- ⏱️ Timestamp-based referral tracking
- 📊 Analytics dashboard
- 🏆 Credit and leaderboard system
- 🔔 Real-time notifications
- 🤖 AI chatbot assistance
- 📧 Email notifications
- 📱 SMS integration
- 📁 CSV data export
- 📝 Audit trail
- 🔒 JWT authentication
- 🛡️ Secure API validation and request protection
- 🎙️ Speech-to-text input

### 🛠️ Tech Stack

`React.js` `Node.js` `Express.js` `MongoDB` `JWT` `Tailwind CSS` `SSE` `Recharts`
