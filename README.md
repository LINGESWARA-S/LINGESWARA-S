# 🚀 Featured Projects

## 🎓 Admission Referral Management System

A full-stack web platform designed to **digitize and centralize student admission referrals**.

### Key Features

* 🔐 Role-based authentication
* 👥 Student, Faculty, Alumni, Consultant & Admin roles
* 🆔 Unique candidate identification
* 🚫 Duplicate referral prevention
* ⏱️ Timestamp-based referral tracking
* 📊 Analytics dashboard
* 🏆 Credit & leaderboard system
* 🔔 Real-time notifications
* 🤖 AI chatbot assistance
* 📧 Email notifications
* 📱 SMS integration
* 📁 CSV export
* 📝 Audit trail
* 🔒 JWT authentication & security mechanisms

**Tech Stack:** `React.js` `Node.js` `Express.js` `MongoDB` `JWT` `Tailwind CSS`
